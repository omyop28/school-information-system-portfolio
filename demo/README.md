# Demo Guide

This directory documents how the **SMA Negeri 1 Biak Kota School Information System** can be demonstrated for portfolio and technical-review purposes.

## Demo Availability

The full production system is private and is **not exposed as an unrestricted public demo**.

A controlled demonstration may be provided on request when appropriate. This approach protects school data, administrative access, examination workflows, attendance information, and production security configuration.

## Demonstrable Areas

A controlled demonstration can cover selected non-sensitive workflows such as:

- Public school website and responsive interface
- Administration dashboard structure
- PPDB / SPMB configuration and workflow
- USBK portal and examination-management workflow
- GPS-based teacher attendance workflow using safe test data
- Live Sync behavior for supported public content
- Automatic image optimization and WebP processing
- Android WebView client
- Windows Electron client
- Authentication and authorization flow
- Architecture and security-engineering decisions

## Privacy and Security

A demonstration must not expose:

- Student or teacher personal data
- Production credentials
- Database dumps
- Registration documents
- Examination answers
- GPS attendance records
- API tokens or private keys
- Android signing credentials
- Detailed production security configuration

Safe test or synthetic data should be used whenever interactive workflows are demonstrated.

## Repository Scope

This public repository is a **portfolio and technical-documentation repository**. The complete application source, production configuration, credentials, and sensitive operational data remain private.
